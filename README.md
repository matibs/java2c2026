# Café de Especialidad 'Cafeshito'

## Descripción
Este proyecto es una página web desarrollada para la Pre-Entrega del curso de Front-End C2 2026. El diseño utiliza CSS, con Flexbox para la sección de productos y CSS Grid para la sección de reseñas. Es responsive mediante el uso de Media Queries y cuenta con un formulario de contacto integrado con Formspree.
